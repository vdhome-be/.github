# VDHome

Independent IT and security consultancy from Belgium. We help small and medium organisations run their IT safely:
access and identity, infrastructure, and practical security that holds up in an audit.

- Website: [vdhome.be](https://www.vdhome.be)
- Contact: dev@vdhome.be

## How we work in the open
- Code we publish is open source, licensed per repository; our own products use the EUPL-1.2.
- Please report vulnerabilities privately through GitHub's "Report a vulnerability" on the repository, never in a
  public issue.
- We use AI assistance in development and say so: our work is human-designed and AI-assisted in code, and each
  repository states how.

## Security
Report a vulnerability through the repository's security tab, or by e-mail to dev@vdhome.be.
